# Free Cloud GPU 3D Stickman Video Generator (Google Colab)

Render cinematic 3D stickman fight animations with **zero load on your laptop** using Google Colab's **free Nvidia T4 GPU (16 GB VRAM)**.

---

## 🚀 How to Run in 3 Minutes (No GitHub Needed!)

1. **Open Google Colab**:
   Go to [colab.research.google.com](https://colab.research.google.com) in your web browser.

2. **Upload the Notebook**:
   * Click **Upload** in the dialog.
   * Select [`Stickman_Fight_3D_Colab.ipynb`](Stickman_Fight_3D_Colab.ipynb) from this folder.

3. **Enable Free T4 GPU**:
   * In Colab, click **Runtime** in the top menu $\rightarrow$ **Change runtime type**.
   * Under Hardware accelerator, pick **T4 GPU** (Free).
   * Click **Save**.

4. **Click Run All**:
   * Press `Ctrl + F9` or click **Runtime** $\rightarrow$ **Run all**.
   * In ~1–2 minutes, Google's GPU will install Blender, construct the 3D scene, render the video, and automatically pop up the file download dialog to save `stickman_fight_3d.mp4` to your laptop!

---

## 🥋 What the Scene Contains
* **Dual Neon Fighters**: Cyan Striker (`#00f0ff`) vs. Crimson Rival (`#ff0055`) with high-intensity emission shaders.
* **Seamless 270° 3D Orbiting Camera**: Sweeps continuously in an aerial arc around the suspended fighters.
* **0.15x Bullet-Time Slow Motion**: Parabolic jump and time dilation.
* **3D Expanding Shockwave Rings**: Ignites at the point of impact on the arena floor.
* **Export**: Native 1080p H.264 MP4.
